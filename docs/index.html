VidAssist API

Universal video & audio downloader API + demo UI.

Install

npm install github:pixel-1coder/vidassist.api

npm start

Open http://localhost:3000

Endpoints

  • GET /api/health
  • POST /api/info — {"url":"..."}
  • GET /api/download?url=...&type=video|audio&title=...

Supported

YouTube / Shorts, TikTok, Instagram Reels (public), Gaana, Hungama, Likee, Amazon MiniTV, and many more via yt-dlp.
